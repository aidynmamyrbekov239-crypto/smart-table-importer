# Таблица из файла

Статический сайт для загрузки Excel, Word и изображений с таблицами. Откройте `index.html` в браузере либо опубликуйте папку на GitHub Pages.

Для работы с Excel, Word и распознаванием изображений при первом запуске нужен интернет: библиотеки загружаются из CDN. Сами выбранные файлы не отправляются на сервер приложением — обработка происходит в браузере.

## Ограничения

- Excel/CSV: считывается первый лист, первая строка становится заголовками.
- DOCX: лучше всего работают строки, разделённые табуляцией или двумя и более пробелами.
- JPG/PNG: текст распознаётся OCR; для качественного результата используйте ровное, чёткое фото таблицы.
